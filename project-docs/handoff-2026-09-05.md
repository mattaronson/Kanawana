## The five rules that actually govern the work

Not style preferences. Each exists because it was violated and cost something.

1. **A negative result from a tool is a fact about the tool, not about the world.**
   A 403, a blocked domain, an empty search — record as an ACCESS FAILURE with the
   untried routes named. Never as "does not exist."
2. **"X appears nowhere in this project" is one grep, and must never be written without
   running it.** Violated twice on 2026-09-05, thirty minutes apart, both times about a
   real person already in the KB (`f_4802`, `f_4819`).
3. **Where a document is known only from an image, "the document does not say X" must be
   written as "the image does not show X."** A crop removes evidence silently (`f_4834`).
4. **Corrections go in place and visibly.** Superseded facts are prefixed
   `[SUPERSEDED <date>: …]` and kept, never deleted. Articles state what they previously
   got wrong rather than quietly fixing the sentence.
5. **Oral history yields to documents only where they DIRECTLY conflict** (operator
   directive, 2026-07-07). An illegible document states nothing to be overridden — where
   a plaque is faded, a person who was there supplies what the strokes cannot.

## Operational conventions

- **Commit messages carry the research record.** Write to a file with a quoted heredoc
  (`<<'MSG'`) then `git commit -F <file>`. Never `-m` with a multi-line string.
  Merges to main use a **merge commit, never a squash**.
- **A hook blocks direct commits to `main`.** Work on a branch and open a PR.
- **Do not hand-edit generated files.** `wiki/people/multi-year-index.md` and
  `kb/plaque-audit/person-index.json` come from `scripts/plaque/build_index.py` then
  `build_table.py`; `data_integrity.py` asserts they match their builders.
- **Do not run `scripts/verify/seed_read_state.py`** — it clobbers hand-written
  provenance and reserialises 1,563 records, so the damage hides in a 28,000-line diff
  (`p_411`).
- Every article edit: update the `*Status: … | Sources: N*` header, keep footnote
  numbering contiguous, refresh `sources_cited` in `wiki/articles.json` (A2 fails
  otherwise). Log every atomic unit to `logs/pipeline.log`.
