**Concordia Archives Structure (P0145/12B Kamp Kanawana):** The full sub-series breakdown is:
- 12B01: General administration (season reports, committee minutes, camper lists, 1910-1970)
- 12B02: Financial administration
- 12B03: Land, facilities, equipment, supplies
- 12B04: Communications (brochures 1921-2001, newsletters, videos, artwork)
- 12B05: Staff, counsellors
- 12B06: Campers (place mats, reunions materials)

All already documented in the project.
